# 자동 사진 보정 1차 검수 — 2026-11-11

## 구현 범위

`marketing/`만 변경했다. 원본 루트 실측 HTML·로고·캐릭터 해시가 모두 일치하고 기존 실측의 초기 실행은 HTTP 200, 11개 버튼, JavaScript 오류 없음으로 확인했다. 마루견적 저장소·계산·시트 구조는 이번 작업에서 수정하지 않았다.

독립 작업 브랜치 `feature/safe-auto-photo-20261111`에서 구현·검증했다. 처음에는 main 배포를 보류했으며, 이후 사용자의 배포 지시에 따라 검증한 변경을 배포한다.

### 실제 동작

- `01 사진 & 디자인` 안의 독립 자동 보정 작업 화면. 사진 1–30장을 등록하면 순서대로 분석한다. 기존 1–10장 제작·편집기를 덮어쓰지 않는다.
- EXIF 원본 바이트를 보존하고 브라우저의 EXIF 방향 디코딩을 사용한다. 방향 6 JPEG의 시각 방향과 픽셀 수를 Chromium·WebKit에서 검사했다.
- 640px 분석용 이미지의 상단 구조 후보에서 경계선을 검출하고 Hough 투표·회귀로 선을 추정한다. 벽·문틀·창틀을 의미적으로 인식하는 AI 모델은 아니다.
- 여러 분산된 수직선과 독립 수평선이 일치할 때만 회전을 적용한다. 회전 ±1.5°, 예상 잘림 6%를 넘거나 근거가 부족하면 원본을 유지하고 검수 사유를 기록한다.
- 수직 수렴의 제한적 projective 변환 계산·역변환·안전 크롭을 구현했다. **수평을 포함한 모든 원근/카메라 자세를 교정하는 기능은 아니다.** 알려진 선 좌표에서 projective 수학 검사를 통과했으나, 왜곡 테스트 사진에서 근거가 부족한 경우에는 원근 수정을 보류했다. 실제 현장 사진의 자동 원근 보정 성공률은 검증하지 않았다.
- 전체 색상 보호가 기본이다. 바닥 자동 식별 모델이 없어 기본 상태에서 노출·대비·화이트밸런스를 바꾸지 않는다. -0.16~+0.25EV 범위의 노출 추천을 계산하되 사용자가 보호 경계를 직접 확인한 사진만 비자재 영역에 적용한다. 경계 아래와 그 위 안전 여백은 노출 보정에서 제외한다. 대비 자동 변경은 하지 않는다.
- 원본/보정 슬라이더 비교, 사진별 승인·원본 복원·원본 기반 재보정, 일괄 승인, 승인 사진 ZIP, 원본 ZIP, 사진별 원본 해상도 저장.
- 보정 PNG는 원본 방향 기준 해상도를 유지한다. 변경이 없는 사진은 원본 파일 바이트를 그대로 내려받는다. PNG 생성 시 색상 필터는 보호 영역에 적용하지 않고 기하학적 재배치/보간만 허용한다.
- 검수 기록 JSON에 원본 크기·EXIF·기하 보정·보호 영역·승인·복원 이력을 포함한다. 1차 모듈에서 생성형 픽셀을 만들지 않는다.
- 승인 후 선택한 1–10장만 기존 디자인 도구에 연결한다. 연결 전 기존 현장을 보관함에 별도 프로젝트로 보존한다. 자동 보정 배치의 원본은 그대로 유지한다.
- 기존 IndexedDB 스키마를 변경하지 않고 `state.autoPhotoBatch`에 자료를 추가한다. 기존 전체 백업·복원에 원본·검수 이력도 포함된다. 잘못된 보정 파라미터·보호 영역의 복원을 거부한다.

### 의도적으로 자동 적용하지 않는 기능

- 카메라별 렌즈 프로필 기반 왜곡 교정: 미구현. EXIF 방향 처리와 별개다.
- 바닥 의미 분할·감지 신뢰도: 미연결. 사진 전체를 보호하는 안전한 기본값을 사용한다.
- 잡동사니 자동 감지·생성형 제거: 2차 미연결. 기존 선택 영역 AI 편집은 삭제하지 않았다. 사용하려면 기존 보안 서버·인증·별도 API 비용·원본 외부 전송 동의가 필요하다. ChatGPT 구독은 API 비용을 포함하지 않는다. 새 모듈은 비밀키를 저장하거나 외부 사진 API를 호출하지 않는다.
- 넓은 바닥/배경을 재생성하는 자동 승인: 없음.

## 처리 한도

원본 장당 20MB, 합계 80MB, 배치 30장. 사진은 4,800만 화소·한 변 12,000px 이내다. 원본은 보존하지만, 실제 보정 출력은 메모리 보호를 위해 iPhone/iPad UA에서 16,777,216화소, 그 외에서 2,400만 화소로 제한한다. 한도를 넘으면 축소 출력으로 속이지 않고 원본 저장·다른 기기 사용을 안내한다. ZIP은 160MB 한도이며 초과 시 사진별 저장을 안내한다. 여러 기기의 실제 메모리/OS 저장 대화상자는 기기별 확인이 필요하다.

## 구글시트 제품·모델 연동 후속

실제 서버는 `https://maru-calc.pages.dev/api/marketing-products`다. 서버가 생성한 안전한 실제 피드는 1,365개 행, 정상 파싱 162개 제품군, 1,347개 모델이다. 원본에 동일 모델·다른 규격인 제품군 1건은 검수 대상으로 보류했다. 기존 수동 도감과 충돌하는 항목은 자동 덮어쓰지 않는다.

직접 서버 연결이 실패하면 GitHub Pages의 마지막 정상 5개 필드 피드로 대체한다. 화면에 대체 자료 사용과 발행 날짜를 표시한다. 원본 가격 JSON을 브라우저에 가져오지 않는다. 기존 게시물의 제품 스냅샷은 유지한다.
