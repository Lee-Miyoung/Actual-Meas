# 포트폴리오 상세 — 소재 선택 정보 위계

수정은 `marketing/`의 시공 전후 포트폴리오 상세 화면에 한정합니다.

- 기존 현장 제목과 설명은 사진 캡션으로 보존합니다.
- 사진 아래에 ‘우리 집에 어울리는 바닥재, / 사진과 샘플로 함께 비교해보세요’를 명조 두 줄로 배치합니다. 벽장재 프로젝트는 첫 줄의 소재 명칭을 벽장재로 표시합니다.
- 서브 카피는 ‘공간의 분위기와 생활 방식에 맞춰 / 마루와 벽장재를 편하게 선택할 수 있도록 안내합니다.’로, 정보 텍스트는 기존 자체 호스팅 Noto Sans KR 계열로 구분합니다.
- `시공 제품`은 해당 렌더링 콘텐츠의 제품 정보에서 브랜드·모델·선택한 세부모델만 표시합니다. 카테고리 대체값이나 미지정 제품은 표시하지 않습니다. 상담 브랜드를 시공 제품으로 추정하지 않습니다.
- `상담 가능 자재`는 대표가 확인한 회사 취급 범위인 동화·구정·노바·한솔·네스트 외를 독립된 회사 메타정보로 표시합니다.
- 배경은 아이보리·웜그레이, 제목과 정보는 딥브라운 계열로 통일합니다. 모든 텍스트는 같은 왼쪽 기준선에 맞추며, 큰 박스·그림자·사진 오버레이는 추가하지 않습니다.
- 원본 로고·사진의 비율·썸네일 순서·확대·저장·프로젝트 구조와 데이터를 유지합니다. 새로운 데이터 스키마나 저장 항목은 없습니다. `previewMeta.productData`는 화면 렌더링에만 쓰는 허용 필드이며 원가·고객 정보는 전달하지 않습니다.

변경 파일: `portfolio-view.js`, `platform-design.js`(화면 제품 메타정보만 추가, 이미지 출력 픽셀 로직은 유지), `editorial.css`(상세 화면 클래스에 한정), `index.html`(캐시 버전), `tests/selection_footer_browser.py`, 이 문서.

검증 결과:
- 실제 모델/세부모델·벽장재 바인딩, 제품 미지정 행 숨김, 회사 취급 브랜드 분리 PASS.
- 기존 제목·사진 바이트·보정값·프로젝트 및 슬라이드 설정 유지 PASS.
- PC, iPad 가로/세로, 390px·320px 휴대폰 크기의 왼쪽 정렬·넘침 방지 PASS.
- 썸네일 이전/다음, 확대, 재접속 후 정보 복원 PASS.
- WebKitGTK 포트폴리오 배치·회전·확대·탐색·재접속 PASS. 실제 iPad 하드웨어 검증을 대신한 것은 아닙니다.
- 기존 콘텐츠/도감/워크플로/타이포그래피 Node 테스트 PASS.
- 4채널·승인·일정·고화질 PNG ZIP·H.264 MP4·전체 백업/복원 회귀 테스트 PASS.
- 보호된 루트 실측 파일 SHA-256 동일, 변경 파일은 marketing/ 내부뿐입니다.

화면 시안의 참고 사진과 제품명은 UI 배치 시연이며 실제 해당 제품의 시공을 입증하는 사진이 아닙니다. 시안 사진은 배포에 포함하지 않습니다.
