# 사진 자동 준비와 저장 수정

2026-11-05. 변경 범위는 `marketing/`이며 실측 앱·원본 자산은 변경하지 않습니다.

## 원인과 수정

기존 디자인 생성은 사진마다 `approved`가 참이어야 실행되어, 제품명이나 메모 수정만으로도 선택 사진의 승인 상태가 해제되고 생성이 다시 막혔습니다. 사진이 없는 경우 짧은 토스트만 표시되어 사용자가 다음 행동을 알기 어려웠습니다. 여러 원본을 동시에 디코딩하고 캐시에 원본 크기로 유지하는 것도 모바일 메모리 부담이었습니다. 사진 다운로드는 자동 클릭만 시도하고 재시도 가능한 파일 링크를 남기지 않았습니다.

- 사진 1–10장 선택 → 보수적인 기본 노출·WB·수평 보정 → 문구와 디자인 3안 자동 준비. 원본 데이터는 그대로 보관합니다.
- 기존 보정값이 있는 사진은 초기 추천으로 덮어쓰지 않습니다. 한 장씩 확정하는 절차는 더 이상 필수 조건이 아닙니다. 이는 AI 잡물체 제거의 외부 전송 동의나 결과 승인 절차를 생략하는 것이 아닙니다.
- 사진이 없을 때 디자인 생성·사진 저장을 누르면 사진 선택 창을 엽니다. 진행·실패 안내를 화면에 유지합니다.
- 새로고침 후에도 저장된 사진으로 디자인을 자동으로 다시 준비합니다. 모델·기본 현장 입력 변경 후에도 다시 준비합니다.
- 기본 화면은 사진·원본 비교·저장 위주로 줄였습니다. 수동 조정과 상세 분석은 `세밀 보정`에 유지합니다. 제품 모델 선택과 검색을 사진 편집 화면에도 배치했습니다.
- 작업 캐시의 긴 변은 최대 2200px로 줄이지만 원본 데이터 URL과 원본 크기 정보는 보존합니다. 개별·전체 사진 저장은 원본에서 긴 변 최대 4096px PNG를 만듭니다. 캐러셀은 1080×1350, 스토리는 1080×1920입니다.
- 선택 시안 3–6장과 보정 사진 전체를 각각 한 개의 ZIP으로 저장합니다. 외부 ZIP 서비스는 사용하지 않습니다. 저장 파일 링크를 남기고 이미지 열기·지원 기기의 파일 공유로 저장할 수도 있습니다. 브라우저 정책으로 자동 다운로드가 차단되면 실제 파일의 다시 저장 링크를 사용합니다.

## 첨부 제품표

대표 제공 표의 91개 제품 계열과 377개 세부 모델·색상명을 `data/provided-products.json`과 `catalog-seed.js`에 가격 없이 저장했습니다. 사용자 입력 없이 도감에 추가하며 기존 동일 ID/동일 제품은 덮어쓰지 않습니다. 추가 전 current 사본을 별도 IndexedDB 키에 저장하고 같은 트랜잭션으로 도감을 확장합니다. `providedCatalogueVersion`은 보관·전환 시 유지합니다.

브랜드 머리글이 잘린 첫 그룹과 머리글이 없는 그룹은 브랜드를 추정하지 않았습니다. 모델·표에 보이는 규격·구성·박스 면적은 활용할 수 있습니다. 색상 종류 수는 실제 현장에 사용한 색상명과 구분합니다. 누락된 규격을 채우거나 면적을 계산해 원문을 수정하지 않습니다. 노바 뉴트로의 구성 수량/면적 등 서로 맞지 않을 수 있는 표기는 검토 상태로 남겼습니다. 단종·출시 전·재고 없음 표기는 기본 선택 목록에서 숨기되 기존 선택과 전체 도감에는 유지합니다.

규격·구성·박스 면적·색상 종류 수를 자동 문구에 포함합니다. 가격 필드와 금액은 없습니다. 표의 방염 문구는 인증 자료 확인 없이 성능 보장 문구로 넣지 않았습니다. 데이터는 제공된 표의 기록이며 현재 제조사 사양·판매 가능 여부를 자동 확인한 정보는 아닙니다.
