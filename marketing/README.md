# 청인마루 콘텐츠 스튜디오 — 개발 중

독립 경로 `marketing/`. 루트 실측 앱과 데이터는 변경하지 않습니다. 빌드나 패키지 설치 없이 저장소 루트에서 `python -m http.server 8000 --bind 127.0.0.1`로 실행합니다. 개발 작업은 기존 체크아웃을 사용하며 사용자가 요청하지 않으면 worktree를 만들지 않습니다.

## 구현 범위

- JPEG/PNG/WebP 4–10장 업로드. 원본 보존, 사진별 자동 노출과 수동 색온도·대비·회전·원근·구도, 원본 비교, 보정 PNG 저장.
- 3개 독립 디자인과 사진 순서, 시안별 5장 PNG 출력. 캐러셀 1080×1350 / 스토리 1080×1920. 출력 크롭은 중앙 기준이므로 중요한 부분이 잘리지 않았는지 확인해야 합니다.
- 메모 기반 설명글·해시태그·고정댓글·릴스 구성안. 생성형 AI 또는 영상 렌더링이 아닙니다.
- 기존 캐릭터 원본을 마지막 카드에 선택적으로 사용. `icon.jpg`는 기존 앱 아이콘으로 사용하며 공식 로고 원본 여부는 미확인입니다.
- 제품군 참고 도감, 수동 일정·팔로워·상담·계약 기록, IndexedDB 자동 저장과 원본 포함 JSON 백업/복원.

마케팅 저장소는 `cheonginmaru-marketing-v1` IndexedDB입니다. 루트 앱 `cm_auth_session`, `cm_v20_records` 등 localStorage에는 접근하지 않습니다. 사진을 외부 전송하지 않습니다. 브라우저 저장소 용량 제한과 기기 유실에 대비해 백업을 보관하세요. 복원은 현재 프로젝트 백업 다운로드와 확인 후 실행합니다. 백업은 개인정보를 포함할 수 있습니다.

## 아직 완료하지 않은 요구사항

최종 개발 패키지의 마케팅 기준 index.html, 01–05 지침, 실제 시공 사진은 현재 전달되지 않았습니다. 따라서 기존 마케팅 메뉴·저장 형식의 호환성과 원본 패키지 지침 준수 여부, 실제 시공 사진 미적 품질은 검증하지 못했습니다. 제품 도감은 실제 브랜드/모델 데이터가 아닌 제품군 안내입니다. AI 자동 화이트밸런스·원근 분석, 선택 마스크 잡물체 제거, 인증된 AI 서버·비용/사용량 관리·외부 전송 동의, SNS/고객 시스템 연동, 캐릭터 표정 재편집 및 릴스 영상 출력은 미구현입니다. API 키를 받거나 공개 HTML에 입력하는 기능은 없습니다. AI 편집 서버를 구현할 때는 배포 호스트·인증 제공자·편집 서비스·예산 정책을 확정해야 합니다.
