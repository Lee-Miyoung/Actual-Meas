최소 구현 범위

구분첫 구현확인·추가 자료
도면이미지 업로드, 수동 벽선·꼭짓점 이동, 기준 길이로 축척 설정, 벽 높이·두께, 문·창 편집실측 치수와 개구부 정보. 자동 인식은 후속 기능.
3D 공간평면 벽으로 구성된 단층 공간, 면 선택, 회전·확대·이동, 실행 취소곡면·복층·경사 천장·정교한 가구 모델링은 후속 범위.
기존 데이터만 가능브랜드·제품명·모델·규격·분류 검색, 선택·비교 목록규격 문자열은 원문 표시. 크기·단위·방향 확인 전 자동 적용하지 않음.
텍스처 필요검증된 제품만 바닥·벽에 적용, 실제 반복 크기·결 방향·줄눈 반영정면 고해상도 이미지, 실제 촬영 범위(mm), 방향, 제품 식별 매핑, 사용 권한. 광택·요철은 별도 맵 또는 검증값.
비교·저장동일 시점 A/B, PNG 내보내기, 미확인 배지·선택 제품 기록실제 전후는 기준 사진/재질 필요. iPad Safari 실기기 검증 필요.

제품 상태를 숨기지 않습니다

제품 데이터만 확인됨 제품 검색·선택 가능 / 사실적인 재질 적용 불가

텍스처 검증 완료 제품과 이미지·실제 크기·색 기준 확인 후 적용 가능

텍스처 검토 필요 이미지가 있어도 제품 매핑·실물 크기 미확인 시 적용 보류

읽기 전용 연결 설계

기존 GET /api/marketing-products → 새 사이트의 읽기 전용 중계 → 허용한 5개 필드만 화면 전달. 기존 Worker·견적·가격·원본 시트 수정 없음. 고정한 원본 호스트와 경로만 GET 요청하고 로그인 쿠키·가격 API는 전달하지 않음.

현재 응답 구조: schema, generatedAt, source, digest, rows[{brand, name, model, spec, category}]. 텍스처·제품 ID 필드는 없음. 별도 매핑은 5개 필드 조합으로 관리하되 동일 행 충돌·제품명 변경 시 재확인.

현재 CORS 허용 출처는 https://lee-miyoung.github.io 한 곳. Sites 브라우저 직접 연결은 불가하므로 새 사이트 서버에서 GET 중계 예정. 실제 운영 API 도메인, 응답, 연결 가능 여부는 아직 검증하지 않음.

원본 캐시는 최대 900초. generatedAt은 응답 생성 시각이며 자재 데이터의 최종 수정일을 뜻하지 않음. 오류 시 목록을 임의 생성하지 않고 재시도 안내와 마지막 성공 시각을 표시.

아이패드·색상·저장 기준

44px 이상 터치 영역, 가로 화면 좌측 보정·중앙 뷰어·우측 제품, 세로 화면 단계별 패널. 제스처는 뷰어 안에서만 처리하며 페이지 스크롤 유지. 화면 회전 후 상태 유지, WebGL 메모리 제한 및 PNG 저장/공유를 실기기 검증.

검증 텍스처도 화면 밝기·True Tone·조명·디스플레이에 따라 실물과 차이가 있습니다. 실물 샘플 확인 안내. 가짜 나뭇결이나 임의 제품색은 생성하지 않음.

도면·선택 상태는 우선 기기 내 저장과 프로젝트 JSON 내보내기. 클라우드 저장·로그인·공유는 후속 범위. 이 시안은 도면과 입력을 영구 저장하지 않습니다.
