# 마루니·루루 현장 이야기

사진 & 디자인 상단의 독립 편집기입니다. 기존 사진 보정·견적·저장 데이터는 변경하지 않습니다.

- 실제 사진 전체를 원본 비율로 표시하며 여백을 사용합니다. 사진 이동·크롭·색 보정은 하지 않습니다.
- 마루니·루루 터치 이동, 두 손가락 크기 조절, 좌우 반전, 여러 캐릭터와 말풍선을 지원합니다.
- 사진 1장을 불러온 뒤 현재 사진을 6컷에 사용하거나 장면별 사진을 넣을 수 있습니다.
- 6장 순서 변경·복제, 독립 IndexedDB 자동 저장, 프로젝트 ZIP 백업·복원, 1080×1350 PNG와 ZIP 출력을 지원합니다.
- 공식 PNG 6종(각 3종)을 원본 바이트 그대로 등록했습니다. 예약 60개 중 미확인 54종은 확인 필요로 표시하며 선택할 수 없습니다.
- 반전 시 명찰 글자도 함께 뒤집힙니다. 원본을 재창작하지 않습니다.
- 물리 아이패드 Safari의 손가락 조작과 사진 앱 공유는 미검증입니다. PointerEvent 자동 검증과 브라우저 저장·출력 통합 검증을 통과했습니다.
- Node 검증 69개 통과.
