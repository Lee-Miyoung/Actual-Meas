# 마루니·루루 현장 이야기 — 6컷 편집기

## 승인 범위 및 연결

- `marketing/index.html` → 사진 & 디자인 → **마루니·루루 현장 이야기**.
- 최신 main을 기준으로 독립 패널과 스크립트/CSS 연결만 추가한다.
- 기존 실측·견적·사진 보정·콘텐츠 생성·마케팅 저장 데이터는 변경하지 않는다.
- PR #3의 단컷 캔버스·이미지 불러오기·비율 유지·반전 개념을 확장했다.
- PR 병합·운영 배포는 별도 승인 대상이다.

## 사용 방법

1. 프로젝트 이름을 입력하고 현재 컷부터 현장 사진 1–6장을 선택한다. 6컷 범위를 넘으면 첫 컷부터 이어 배치한다. 기존 사진 교체 전 확인한다.
2. 공식 캐릭터 목록에서 마루니·루루를 선택한다. 같은 장면에 함께 배치할 수 있다.
3. 캐릭터를 눌러 선택하고 끌어 이동한다. 두 손가락 또는 크기 슬라이더로 조절한다. 빈 사진을 눌러도 캐릭터가 점프하지 않는다.
4. 말풍선을 추가하고 화자·문구·위치를 지정한다. 말풍선은 캐릭터와 별도로 움직인다. 한 장면은 캐릭터와 말풍선을 합해 최대 12개다.
5. 사진은 기본 잠금이다. 사진 조절을 켜면 구도 이동·확대가 가능하다. 사진의 색·질감 필터나 생성형 보정은 적용하지 않는다. 4:5 비율에 맞춘 잘림은 미리보기로 확인한다.
6. 컷 선택·다른 컷에 복제·앞뒤 순서 이동·뒤로 한 단계로 6컷을 구성한다. 장면을 복제한 뒤에도 문구·배치는 독립적이다.
7. 현재 컷 PNG 또는 6컷 PNG·ZIP을 준비한다. 모든 PNG는 1080×1350이다. 미등록 사진 컷은 출력을 차단한다.
8. 다른 기기로 옮기려면 **편집 프로젝트 ZIP**을 백업하고 복원한다. PNG 출력 ZIP은 편집 프로젝트와 다르다.

## 공식 자산 현황 — 60개 준비 완료라는 뜻이 아님

`assets/characters/manifest.json`에는 마루니 30개·루루 30개, 총 60개 고정 ID를 예약했다.

- 실제 등록: **6종(마루니 3종·루루 3종)**.
- 미등록: **54종**. 원본이 없는 항목은 `pending`이며 선택 목록에 표시하지 않는다.
- 사용자 제공 개별 PNG 6종을 기존 자료에서 찾아 원본 바이트 그대로 복사했다.
- 각 자산에 파일명·출처·버전·SHA-256·크기·투명 영역 범위를 기록했다.
- 자산 클릭 시 SHA-256을 확인하고 프로젝트에 PNG 자체를 복사해 둔다. 나중에 공식 목록이 바뀌어도 기존 프로젝트 그림은 바뀌지 않는다.
- 임의 포즈 생성, 다른 그림체 대체, 복제·반전으로 종류 수를 채우지 않는다.
- 마루니의 명찰 글자가 뒤집히지 않도록 반전을 금지했다. 루루는 허용한다.
- 사용자가 보유한 투명 PNG를 직접 추가할 수 있다. 직접 추가한 파일은 공식 목록 등록으로 계산하지 않는다.
- 60종 완료에는 나머지 개별 공식 원본 확보·대조 검수가 필요하다.

등록된 원본은 다음과 같다. 파일명상 ‘생각하는 포즈’는 실제 이미지가 양손 설명 동작이므로 선택 화면에는 실제 동작을 표시한다.

## 파일 역할

- `maruni-story-core.js`: 버전·장면·레이어 스키마 검증, 장면 복제 시 ID/화자 연결 재설정, 구도·비율·줄바꿈 계산.
- `maruni-story-render.js`: 미리보기와 출력 공통 렌더러. 선택 표시만 편집 화면에 적용. 자체 호스팅 한글 글꼴을 기다린 뒤 렌더링.
- `maruni-story-store.js`: 독립 IndexedDB `cheonginmaru-maruni-story-v1`. 프로젝트/미디어의 원자적 저장. 미디어 복합 키 `[projectId,id]`로 프로젝트 복제·삭제 영향 분리.
- `maruni-story-export.js`: PNG 순차 생성, 기존 fflate로 ZIP, 원본을 포함하는 프로젝트 백업/복원. 잘못된 ZIP 경로·개수·용량·형식 거부. 복원은 새 프로젝트 ID로 저장.
- `maruni-story.js`: 패널·자동 저장·프로젝트 목록·장면·터치·자산 선택. 기존 전역 state/persist/card/download 재정의 없음.
- `maruni-story.css`: `#maruni-story` 안에만 적용. 44px 터치 영역, 아이패드 가로/세로 레이아웃.

## 저장·메모리·출력 제한

- 사진 PNG/JPEG/WebP, 개별 25MB·4800만 화소·한 변 12000px 이하. HEIC는 JPEG 변환 필요.
- 프로젝트 전체 원본 이미지 합계 240MB 이하.
- 미리보기는 긴 변 최대 2048px, 캐시 최대 4개. 원본 Blob은 변경하지 않는다.
- PNG 출력 시 원본에서 한 장씩 디코딩하고 출력한다. 원본 디코드 캐시는 1개이며 사용 후 해제한다.
- 자동 저장은 변경 후 550ms. 저장 실패를 성공으로 표시하지 않고 ZIP 백업을 안내한다.
- 저장 완료된 내용은 새로고침 후 복원된다. 브라우저 강제 종료 직전 아직 저장 중이던 내용까지 보장하지 않는다.
- iPad의 공유 API 지원 시 이미지 공유 버튼을 제공하고, 미지원 시 PNG별 저장·ZIP 파일 저장을 제공한다. 사진 앱에 저장 완료했다고 자동 표시하지 않는다.
- 기기 간 자동 동기화와 기존 앱 사진의 직접 연결은 이번 범위에 포함하지 않는다.
